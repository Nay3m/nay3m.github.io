# Jannatul Nayeem Wildlife Portfolio

A no-build, GitHub Pages-ready portfolio site for Jannatul Nayeem, a Zoology undergraduate focused on wildlife conservation, ecology, biodiversity, species monitoring, habitat assessment, and GIS for wildlife research.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and `Jannatul-Nayeem-CV.docx` to the repository root.
3. Open the repository’s **Settings → Pages**.
4. Select **Deploy from a branch**, choose the default branch, and select `/ (root)`.
5. Save. GitHub will provide the public site URL.

## Before publishing

- Replace `www.linkedin.com/in/[add-profile-slug]` in `index.html` with the verified profile URL.
- Confirm the internship year and duties.
- Add confirmed responsibilities for Butterfly Fair and Scout experience if desired.
- Confirm the CGPA scale, second-year CGPA, SSC GPA, and language proficiency.
- Keep `Jannatul-Nayeem-CV.docx` in the same folder if the Download CV link is retained.

The site uses Google Fonts with system fallbacks, so it remains readable if the hosted fonts are unavailable.
